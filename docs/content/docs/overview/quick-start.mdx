# Quick Start

The current version runs `web/`, `server/`, and PostgreSQL together.

## Run locally

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
cp .env.example .env
docker compose -f docker-compose.local.yml up -d --build
```

Open `http://localhost:3000`.

## Run with Docker

```bash
cp .env.example .env
docker compose up -d --build
```

## First-time setup

- Open Settings and enter your `Base URL`, `API Key`, and model names.
- Open `/prompts` to fetch prompt repositories directly from the browser and cache them in IndexedDB.
- Configure WebDAV if you want to synchronize canvases, assets, and generation history across devices.

Accounts and sessions are stored by the PostgreSQL service. Canvas projects, My Assets, generation history, and API keys remain browser-local until the account migration slice is complete.
